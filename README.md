TiffinAI – Sales and Demand Prediction

About the Project

TiffinAI is a machine learning project designed to predict tiffin sales and demand using historical sales data.

Technologies Used

- Python
- Pandas
- Scikit-learn
- Random Forest Regression
- OneHotEncoder
- ColumnTransformer
- Machine Learning Pipeline

Project Features

- Data preprocessing
- Categorical feature encoding
- Sales and demand prediction
- Machine learning model training

Objective

To explore how machine learning can help predict food demand and support better planning.
